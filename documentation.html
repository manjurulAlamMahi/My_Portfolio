MaxDev — Portfolio Template

Documentation · Version 1.0

1. Overview

MaxDev is a static, no-build HTML/CSS/JS portfolio and personal-site template built on Bootstrap 3. There is no build step, package manager, or compiler required — open any .html file directly in a browser, or upload the whole folder to any static web host.

Pages included

FilePurpose
index.htmlHome — hero, top projects, contact CTA
about.htmlAbout — bio, stats, services, tools, testimonials
resume.htmlResume — skills, experience timeline, education
projects.htmlProjects — filterable project grid
project-details.htmlCase-study page (reads ?slug= from the URL)
contact.htmlContact form + details
ai-chat.htmlOptional AI-assistant demo page

2. Customizing your content

Your name, role and photo

The sidebar/profile block (name, role, location, avatar) is repeated at the top of the <body> in every page — search for sidebar-name in each HTML file and replace the text and assets/images/avatar-placeholder.svg reference with your own photo.

Projects

All project content lives in one file: assets/js/projects-data.js. Edit the window.PROJECTS array — the projects grid, filters, and case-study page all render from it automatically. No HTML editing required.

Skills / Resume

Edit assets/js/skills-data.js (window.SKILLS) to change the technical skill bars and soft-skill cards on the Resume page.

Contact form

The form in contact.html posts to a placeholder Formspree endpoint. Before going live, replace:

<form id="contact-form" method="post" action="https://formspree.io/f/your-form-id">

with your own Formspree endpoint (or any other form backend that accepts a standard HTML POST).

AI Assistant page (optional)

ai-chat.html is a lightweight, client-side FAQ demo — it keyword-matches visitor questions against a small knowledge base in assets/js/ai-chat.js and has no server or API dependency. Edit the knowledgeBase array to change its answers, or remove the page and the .ai-fab button / "AI Chat" tab entirely if you don't want it.

4. Dark mode

Toggled by the button in the floating nav (desktop) or the floating circular button (mobile). The choice is saved to localStorage under the key maxdev-theme and respects the visitor's OS-level color scheme on first visit. No configuration needed.
